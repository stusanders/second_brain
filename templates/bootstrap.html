PDF, Word, PowerPoint, Excel, CSV, text or markdown. What makes a good corpus is the same concepts recurring across many documents — that recurrence is what gets collapsed into shared pages. Unrelated material has nothing to merge.

What happens next

  1. Read — each document is stored unchanged and read in full.
  2. Extract — the concepts each document covers, with the passages evidencing them.
  3. Consolidate — concepts appearing across many documents become one page those documents feed, not one page each.
  4. Write — each page is written once, with every relevant source in view.
  5. Map — pages are grouped by how they actually link to each other.
  6. Review — predicted gaps in the corpus, plus any contradictions between your sources.
